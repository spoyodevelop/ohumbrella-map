# DB 스키마 적용

서버는 시작할 때 DB를 변경하지 않는다. 필요한 테이블이나 검증 트리거가 없으면 시작에 실패하고 마이그레이션 명령을 안내한다.

DB를 처음 만들거나 스키마 변경을 배포할 때, 대상 DB의 `TURSO_DATABASE_URL`과 원격 DB의 `TURSO_AUTH_TOKEN`을 설정한 환경에서 다음 명령을 먼저 실행한다.

```sh
npm run db:migrate
```

이 명령은 날씨 테이블과 인덱스, 검증 테이블과 트리거를 준비한다. 사용하지 않는 `forecast_accuracy_stats` 테이블과 오래된 정확도 뷰를 삭제한다. 기존 테이블의 데이터도 삭제되므로 대상 DB를 확인한 뒤 실행한다. 원본에 있으나 검증 테이블에 없는 표본을 보충하며, 표본 보충은 기본키와 `INSERT OR IGNORE`로 재실행할 수 있다.

명령이 성공한 뒤 PM2 서버를 시작하거나 재시작한다. 조회 전용 Vercel API는 이 명령을 실행하지 않는다.
