# 날씨 데이터 저장과 조회 책임

- `weather_observations`는 기상청 실황의 시각별 원본을 저장한다. 실황을 다시 받으면 같은 시각·시군구 행을 갱신한다.
- `weather_forecasts`는 발표 회차와 예보 대상 시각별 원본을 저장한다. 검증 통계는 이 두 원본 테이블을 결합해 계산한다.
- `hourly_weather`는 현재 날씨 API를 위한 조회용 테이블이다. 새 실황 행에는 관측값만 저장하고 예보값 `pop`·`sky`는 비워 둔다. 예보 수집은 최신 실황 행에 첫 예보값을 반영한다.
- 실황 재수집은 같은 행의 `pop`·`sky`를 덮어쓰지 않는다. 현재 날씨 조회는 최신 행의 예보값이 비어 있으면 지역별 이전 값을 조회용으로만 사용하고, 그 값이 저장된 실황 시각을 함께 전달한다. 화면은 이전 값을 쓴 경우 몇 시간 전 자료인지 표시한다.

이 테이블은 원본의 대체물이 아니다. 이전 예보값을 보여 주기 위해 새 실황 행의 빈 예보값을 채우지 않는다. 이전 값도 없으면 화면은 예보 자료 없음으로 표시한다.
