# 날씨 데이터 저장과 조회 책임

- `weather_observations`는 기상청 실황의 시각별 원본을 저장한다. 실황을 다시 받으면 같은 시각·시군구 행을 갱신한다.
- `weather_forecasts`는 발표 회차와 예보 대상 시각별 원본을 저장한다. 검증 통계는 이 두 원본 테이블을 결합해 계산한다.
- `hourly_weather`는 시간별 조회 기록이다. 새 실황 행에는 관측값만 저장하고 예보값 `pop`·`sky`는 비워 둔다. 예보 수집은 최신 실황 행에 첫 예보값을 반영한다.
- `current_weather`는 화면 조회용 최신 상태를 시군구마다 한 행씩 보관한다. 새 실황은 관측값만 갱신하고 기존 예보값과 출처 시각을 유지한다. 새 예보는 값과 출처 시각을 갱신한다. 현재 날씨와 시도 통계 API는 이 테이블을 읽는다.
- 실황 재수집은 같은 `hourly_weather` 행의 `pop`·`sky`를 덮어쓰지 않는다. 화면은 `current_weather`의 출처 시각으로 이전 예보값이 몇 시간 전 자료인지 표시한다.

두 조회용 테이블은 원본의 대체물이 아니다. 이전 예보값을 보여 주기 위해 새 실황 행의 빈 예보값을 채우지 않는다. 이전 값도 없으면 화면은 예보 자료 없음으로 표시한다.
