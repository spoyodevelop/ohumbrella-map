# 날씨 데이터 저장과 조회 책임

- `weather_observations`는 기상청 실황의 시각별 원본을 저장한다. 실황을 다시 받으면 같은 시각·시군구 행을 갱신한다.
- `weather_forecasts`는 발표 회차와 예보 대상 시각별 원본을 저장한다. 검증 통계는 이 두 원본 테이블을 결합해 계산한다.
- `hourly_weather`는 현재 날씨 API를 위한 조회용 테이블이다. 새 실황 행에는 관측 시각과 일치하는 예보 중 가장 최근 발표분의 강수확률(`pop`)과 하늘상태(`sky`)를 함께 채운다. 예보가 나중에 도착하면 최신 실황 행의 시각과 일치할 때만 갱신한다.
- 실황 재수집은 같은 행의 `pop`·`sky`를 덮어쓰지 않는다. 현재 날씨 조회는 해당 지역의 최신 행을 읽고, 그 행에 `pop`이 없으면 그 지역의 마지막 유효 `pop`을 조회용으로만 사용한다.

이 테이블은 원본의 대체물이 아니다. 예보가 실황보다 먼저 도착하면 예보 원본은 `weather_forecasts`에 남고, 이후 해당 시각의 실황 행을 만들 때 반영된다. 일치하는 예보가 없으면 `pop`·`sky`는 비워 두며, 화면은 하늘상태를 자료 없음으로 표시한다.
