# Prototype boundary data

`korea-sigungu.topo.json` is a static TopoJSON snapshot used only for the map spike.

- Upstream: https://github.com/YangSeungWon/quiz-korea
- Original source: Statistics Korea SGIS census administrative boundaries
- Snapshot: 2025-06-30
- Regions: 252

The production dataset must be replaced with a current official boundary snapshot. In particular, this file predates the four Hwaseong general districts launched in 2026.
