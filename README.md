# ☂️ 아 맞다 우산

**기상청의 강수확률 예보와 실제 강수 관측을 비교해, 우리 동네에서는 얼마나 자주 비가 왔는지 보여주는 서비스입니다.**

강수확률 20% 예보가 나왔던 24,287번 중 실제로 비가 관측된 건 215번, 약 0.9%였습니다.

물론 이 숫자만으로 기상청 예보가 틀렸다고 말할 수는 없습니다. 예보와 관측의 시간, 지역, 강수 판정 기준이 얼마나 일치하는지에 따라 결과가 달라지기 때문입니다.

처음에는 단순한 호기심으로 시작했습니다. 매시간 예보와 실제 강수 기록을 모았고, 그렇게 2년 반 동안 서비스를 운영했습니다.

그런데 문제가 있었습니다.

**서울에 비가 왔다는 사실이, 마포구에 사는 사람에게 얼마나 유용할까요?**

기존 서비스는 전국 17개 대표 지역의 데이터를 비교했습니다. 숫자는 흥미로웠지만, 정작 내가 사는 동네에 대해서는 답할 수 없었습니다.

그래서 V2를 만들었습니다.

17개 지역을 전국 252개 행정구역으로 확장하고, 예보와 관측 데이터를 연결하는 방식부터 지도 시각화까지 다시 설계했습니다.

이제 마포구와 수원시처럼 내가 사는 지역을 선택해 강수확률별 실제 강수 빈도를 확인할 수 있습니다.
